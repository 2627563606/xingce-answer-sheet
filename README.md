# 公务员行测答题卡扫描评分系统

基于 **Python + OpenCV + Streamlit + SQLite + Plotly** 的行测答题卡（130~135 道单选题）扫描识别、自动判卷与统计分析系统。

- 自动识别**纵向 S 型排列**（题号竖排、蛇形走位，如 1-5 一列、6-10 下一列反向），自动检测每列题数并正确映射题号
- **分块式版式**（真实行测卡常见样式：横向多区块 × 每区块首列题号 + 4 选项列，每 5 题一段纵向堆叠、段间留白）自动检测并映射题号，选项为「方框 + 框内印刷字母」时用**整格自适应阈值**判填涂，同样按 **35%** 阈值
- 填涂判定：计算选项圈内涂黑像素占比，**超过 35% 视为选中**（行测“深满匀”要求）
- 附加识别：**准考证号（10-12 位，每位 0-9）** 与 **AB 卷代码**
- 判卷：按五大模块权重计分，总分归一化到 **100 分**，模块配置可自定义
- **题量自适应**：不同地区/试卷类型题量不同（130/135/140 等）——判卷题量默认按**答案文件题数**自动判定，超出模块配置范围的题自动按最后一模块权重计分；也可在侧边栏**手动预设总题量**，小项（模块）划分可在配置页增删改
- **标准答案多方式上传**：Excel / Word / PDF / TXT / CSV，以及**拍照或扫描的答案图片（jpg/png，自动 OCR）**；扫描版 PDF 自动 OCR 回退
- **同一答案多识别方式交叉验证**：对同一份答案文件用多种方式解析（PDF=文字层提取 / OCR 识别；图片=直接 OCR / 增强 OCR；Excel=结构化表格 / 文本模式），各方式结果**一致则可信直接采用，不一致时列出冲突表让用户选择以哪种识别结果为准**
- **答案与卷子强绑定**：每张答题卡答案不同，识别前未上传本卷新答案会醒目提醒并阻断，防止用错答案
- 历史记录（SQLite）：趋势折线图 / 模块雷达图 / **错题热力图**
- 支持**批量导入**多张答题卡一键批改；识别不准可**手动修正**

## 一、依赖安装

```bash
python -m pip install -r requirements.txt
```

依赖：`opencv-python`、`numpy`、`streamlit`、`pandas`、`plotly`（SQLite 为 Python 内置），以及答案文件解析用的 `python-docx`（Word）、`pdfplumber`（PDF）、`openpyxl`（Excel）、`rapidocr_onnxruntime`（拍照/扫描答案 OCR）、`PyMuPDF`（扫描版 PDF 转图）。

> 若系统 Python 无写权限，改用 `python -m pip install --user -r requirements.txt`。

## 二、启动

```bash
cd xingce_answer_sheet
streamlit run app.py
# 或 python -m streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。

## 四、界面使用流程

1. **单张识别**
   - ① 上传答题卡照片（jpg/png）
   - ② 上传**本卷标准答案**（Excel/Word/PDF/TXT）—— 每张答题卡答案不同，**未上传新答案时界面会醒目提醒并阻止识别**；若确为已加载的同一套答案，可勾选「沿用」
   - 点击「识别并批改」→ 右侧展示透视矫正图像（**绿=正确 / 红=错误**，错题标红）+ 识别结果表
2. 展示**总分 + 五大模块得分柱状图**，柱上标注各模块正确率；另有模块雷达图
3. 填写考生姓名（准考证号自动识别）→ 点击「保存记录」写入历史库
   - **手动修正**：在识别结果表中直接修改“识别选项”列 → 「按修正结果重新计分」
4. **批量识别**：上传多张答题卡 + 本卷答案，一键批量批改、一键保存（整批同一套答案）
5. **历史统计**：搜索/删除记录、某考生**总分趋势折线图**、单条记录**模块雷达图**、**错题热力图**
6. **配置管理**：支持**从文件导入答案**写入默认配置；也可直接编辑标准答案 JSON 与模块分值（小项划分可增删行）
7. **题量设置（侧边栏「本卷总题量」）**：不同地区/试卷题量不同，默认 `0=按答案自动`（以答案文件题数为本卷题量）；若需固定题量请手动填写，识别题量不一致时会提示，超出模块配置的题自动按最后一模块权重计分

### 答案文件格式（Excel / Word / PDF / TXT / 图片）

解析器自动识别以下排版（详见 `core/answer_parser.py`，图片 OCR 见 `core/answer_ocr.py`）：

| 格式 | 示例 |
|---|---|
| 两列表格 | 一列题号、一列选项（含表头“题号/答案”） |
| 逐条 | `1.A 2.B 3.C` 或换行 `1.A`、`1 A`、`1、A`、`1：A` |
| 区间 | `1-5 ABCBA` / `6～10: BACDD` / `11--20 CCDDB`（自动展开，**支持双连字符**） |
| **两行式** | **题号行 + 答案行上下对齐**：`1 2 3 4 5` 下一行 `A A C B B`（教辅答案页常见，PDF/OCR 均支持） |
| 多列表格 | 每行多组 `题号\|答案` 成对排列 |
| 拍照/扫描图片 | 答案照片（jpg/png）→ **OCR 识别**（文本模式 + 空间对齐双通道） |
| 扫描版 PDF | pdfplumber 提不出文字时**自动逐页 OCR** 回退 |

> **同一答案多识别方式交叉验证**：对同一份答案文件，系统会用多种独立方式解析并对比——
> - **PDF**：**按页拆分**（每页一个识别方式，如「第1页文字」「第2页文字」）**+ 整份 OCR**
> - **图片**：直接 OCR vs 增强预处理 OCR（放大+对比度）
> - **Excel**：结构化表格 vs 文本模式
>
> 各方式在重叠题号上的结果**一致则直接采用**；**不一致（冲突）时列出冲突表**，让用户**选择以哪种识别结果为准**，并可在冲突表**逐题手动修改**最终答案（其余方式在无冲突题号上补充）。一份文件只识别出一条路径时直接采用。
> **特别说明（教辅答案 PDF）**：不少教辅答案 PDF 最后一页是「**差异题**」（部分地区/卷型与主卷 1-20 题答案不同），系统会把它作为独立的「第N页文字」识别方式，与主卷页冲突时**让用户选择以主卷为准**，避免差异题污染主卷答案。
>
> **答案有效范围**：答案文件可能含本卷之外的题（差异题页、整套答案含多卷等）。上传答案后可设置**有效范围**（如 `1-130`、`1-110,120-130` 多段、`排除:131-140` 排除指定区间），**范围外的题号自动忽略**，不计入判卷。留空表示采用全部。
> **提示**：解析失败或题数不足配置题量时，界面会明确提示。个人练习每卷答案不同，请在**每次换卷后重新上传**本卷答案。

## 五、核心算法说明（对应需求技术要点）

| 需求点 | 实现 |
|---|---|
| 预处理 | 灰度 → 高斯滤波 → **自适应阈值 `cv2.adaptiveThreshold`**（抗光照不均） |
| 答题卡定位 | Canny 边缘 → **面积筛选最大轮廓 → `cv2.approxPolyDP` 取四角** |
| 倾斜校正 | **`cv2.getPerspectiveTransform` 透视变换**；四角被照片裁切时退化为 Otsu 最大亮区最小外接矩形 |
| 填涂判断 | 圈内涂黑像素占比，掩膜取半径 0.6 避开打印描边，**阈值默认 35%**（可调） |
| S 型排列 | y 直方图按行带区分表头/答案区 → x 聚类成列 → 每 4 列一组、行数一致的最长链 → 奇数列自上而下、偶数列自下而上映射题号 |
| 分块式排列 | x 聚类后按大间隙切分区块（每区块=题号列+4 选项列）→ 每 5 题一段纵向堆叠，题号 `=(区块×5+段内行+1)+20×段序`；选项为方框时按**整格自适应阈值黑占比**（避开框内印刷字母干扰）判填涂 |
| 准考证号 | 表头中 8~12 个等距竖排气泡列 → 每位填涂位 → 0-9 数字 |
| AB 卷 | 表头相邻双气泡，一填一空 → A/B |
| 异常排列 | 检测题量与配置不符 / 无法形成矩阵时给出醒目提示，请用户手动确认或修正 |

**计分规则**：每题得分 = 该模块权重；`总分 = Σ(答对题数×权重) / Σ(各模块题数×权重) × 100`（归一化到 100 分）。侧边栏可关闭归一化查看原始加权分。

**题量与模块自适应**：判卷题量默认 = **答案文件题数**（不同地区/试卷类型题量不同，答案即考卷规模）；也可在侧边栏手动指定「本卷总题量」。当题量超过模块配置的最大结束题号时，系统自动把最后一个模块的 `end` 扩展到该题量，保证超出的题（如 131-140 题）按该模块权重正常计分；需要精确划分小项时，在「配置管理」页编辑各模块起止/权重/增删模块即可。

## 七、自测结论

> 样例生成脚本与测试素材（含教辅版权材料）未随本仓库发布，可在本地自行构造答题卡照片与答案文件进行验证。

已实测：干净 / 旋转 7° / 透视+噪声+模糊 / 5 行每列（26 列）四种答题卡样例均 **130/130 全对**，准考证号与 AB 卷识别正确；Excel / Word / PDF / TXT 四种答案文件均 **130 题解析全对**。

真实行测答题卡（**140 题分块式版式**，4 区块 × 每区块 35 行、每 5 题一段）实测：**140 题完整读出**，与图片 OCR 标注的填涂真值 **49/49 全对**；选中题填涂 fill 中位 0.53、未选中 0.29，35% 阈值区分清晰。

## 八、已知限制与使用建议

- **答案强绑定**：因每张答题卡答案不同，识别前必须上传本卷答案（或勾选「沿用」）。换新卷后请务必重新上传该卷答案，否则系统会阻止识别。
- 识别器默认自动适配**两种版式**：标准行测 S 型（每列题数一致、列间充足间距）与**分块式**（多区块 × 每区块题号列+4 选项列）。若版式特殊导致识别错位，界面会提示，并可用「手动修正」逐题改正。
- **140 题卡自动适配**：默认模块配置到第 130 题，但判卷题量默认按**答案文件题数**自动判定——上传 140 题答案后，系统自动把「资料分析」扩展到 140 题计分，无需手动改配置；如需精确控制小项边界，可在「配置管理」页编辑或侧边栏手动指定总题量。
- 照片需清晰、答题卡完整入镜、光照均匀；过大的图片会自动缩小以提速（长边上限 2200px）。
- 侧边栏可调整：填涂阈值、列序方向（左→右/右→左）、最左列读数方向（自上而下/自下而上）、准考证号位数——若整体映射反向可在此切换。
- 准考证号数字列默认自顶向下为 0-9，如版式相反请修改 `core/answer_sheet.py` 中 `digit_order`。
